
# Hotel Room Booking Website

Welcome to the Hotel Room Booking Website project! This is a comprehensive hotel room booking platform built using the MERN stack, featuring Cloudinary for image management, Stripe for payment processing, and a full suite of features typically expected in a hotel booking site.
**Deployed website link:**  https://mern-booking-app-f8im.onrender.com/ 

## Features

User Features:

Search for available hotel rooms based on location, dates, and number of guests.
View detailed information and images of hotel rooms.
Register and log in to manage bookings and view booking history.
Book rooms with an integrated Stripe payment gateway.
Receive booking confirmations and notifications via email.

Admin Features:

Manage hotel room listings, including adding, editing, and deleting rooms.
View and manage user bookings.
Update room availability and pricing.
Access analytics and reports on bookings and revenue.


## Tech Stack

**Frontend:**

React,
React Router (for navigation),
Tailwind-CSS (for styling)

**Backend:**

Node.js,
Express.js,
MongoDB (for database management),
Mongoose (for MongoDB object modeling)

**Cloud Services:**

Cloudinary (for image hosting and management)
Stripe (for payment processing)

## Installation

Install my-project with npm

```bash
git clone https://github.com/yourusername/hotel-room-booking.git
cd hotel-room-booking

```

**1. backend:**

```bash
cd backend
npm install
npm run dev


```

**2. frontend:**
```bash
cd ../frontend
npm install
npm run dev
```
